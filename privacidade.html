Privacy Policy — Games News Drafts

Last updated: November 13, 2026

Data accessed: only the access token granted by the account owner through TikTok Login Kit (scopes user.info.basic and video.upload) and basic profile information (display name / open ID) needed to confirm the connected account.

Use: the token is used only to upload the owner's own videos as drafts to the owner's TikTok account.

Storage: the token is stored only on the owner's personal computer, in a local file readable only by the owner. No data is sold, shared with third parties, or used for advertising or analytics. No data from other TikTok users is collected.

Deletion: revoke access in TikTok > Settings and privacy > Security > Manage app permissions; the local token file is deleted on request.
